Work and Lab

My work is set up as two shelves. Work is program systems built for teacher preparation. Lab is what I build for fun, which is how the Work shelf got its skills.

Shelf 01 / Work

Program systems

  • Instrument design

    Standards-aligned quarterly progress reporting

    Parallel progress-monitoring instruments for two special education licensure tracks, each traceable item by item to state licensure standards, with quarter-based progression built in. Full case study.

  • Data systems

    Program data infrastructure, rebuilt with AI

    A multi-dashboard architecture tracking district partnerships, recruitment, and enrolled candidates for a registered teacher apprenticeship program. When legacy spreadsheets drifted out of sync, I used AI to help me reconcile them into a single source, so a small team can answer time-sensitive questions in minutes instead of meetings.

Shelf 02 / Lab

Built for fun, kept because useful

  • Self-hosted

    Home infrastructure

    A small self-hosted stack: NAS, a dozen-plus Docker services for media, photos, books, and feeds, published through a zero-trust tunnel, with a smart home layer running on Home Assistant.

  • AI / personalization

    Hardcover AI Librarian

    A self-hosted recommender that reads my actual Hardcover history and asks an LLM to suggest books individually tailored to my taste, then verifies every suggestion against real catalog data before showing it to me. Full post-mortem.

  • Tooling

    Receipt scanning for YNAB

    A small vision-model-powered tool that turns grocery receipts into split transactions in my budget, because typing out a Costco run is a life tax I refuse to pay.

  • Games

    Stellaris modding

    Paradox script work: merging conflicting mods, linting mod files, and maintaining a curated Steam Workshop collection.
